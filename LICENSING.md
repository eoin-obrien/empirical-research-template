# Licensing

This file states the licence scope of the template. Keep it when you
replace the template's `README.md`.

- **Template software and infrastructure.** The template's files are
  licensed under GPL-3.0-or-later (see `LICENSE`) unless a file itself
  identifies a different licence. This covers its scripts, hooks, tests,
  checks and configuration.
- **Copies and derivatives.** Template software copied into a project, or
  modified there, remains under GPL-3.0-or-later. Distributing it, or a work
  derived from it, is subject to that licence's terms.
- **CC BY-SA 4.0.** A file that identifies itself as licensed under CC BY-SA
  4.0 is licensed under that licence, including in copies. No file in this
  template carries that identification at present. The licence is not
  applied to `paper/index.qmd` or to manuscript content written in a
  project.
- **New project content.** The template does not license manuscript content
  or research data newly authored in a project created from it. Each
  project decides its own licences, and records the licence of each data
  source in `provenance.yml`.
